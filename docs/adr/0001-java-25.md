# 0001 — Target Java 25 instead of Java 21

- Status: Accepted
- Date: 2026-10-24
- Decided by: product owner

## Context

`CLAUDE.md` and decision D-02 name Java 21. At project start (October 2026) Java 25 is the current LTS
release (GA September 2025), and the build machine has JDK 25 and no JDK 21. Spring Boot 4.1, Spring
Modulith 2.1, Hibernate 7 and Flowable 8 all support Java 25.

## Decision

Compile and run on Java 25 (`maven.compiler.release` = 25). CI and container images use a JDK/JRE 25 build.

## Consequences

- Banks' runtime images must ship a Java 25 runtime; this is noted for the deployment guide.
- Java 25 language and library features (e.g. scoped values, stable virtual threads improvements) are allowed.
- `CLAUDE.md` and `docs/01-decisions.md` D-02 are updated to Java 25.
